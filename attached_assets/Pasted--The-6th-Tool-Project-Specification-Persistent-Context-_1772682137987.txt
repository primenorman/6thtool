# The 6th Tool — Project Specification
## Persistent Context for Replit Agent

### WHAT THIS APP IS
The 6th Tool is a mental performance training platform for baseball players aged 14–25.
It teaches athletes to treat their minds as programmable "bio-computers" using the
Cybernetic Transposition methodology. The platform currently has 42 lessons, 5 interactive
templates, a Neural Lab (pitch recognition games), and the Springer Protocol (bonus module
mapped to Steve Springer's 14-year pro career system). It has 0% completion rate and needs
a full UX and engagement overhaul.

### THE CORE PROBLEM WE ARE SOLVING
The course content is brilliant but packaged like a graduate seminar. Athletes (14–25) need:
- Video-first delivery (not text walls)
- Immediate value on Day 1 (currently requires 33.5 hours before first practice)
- Gamification and streak loops (like Duolingo, but for baseball)
- Mobile-ready PWA with offline capability

### TECH STACK — ALWAYS USE THESE, NEVER DEVIATE
- **Frontend:** React 18 + TypeScript + Tailwind CSS
- **Backend:** Node.js + Express (or Next.js API routes if starting fresh)
- **Database:** PostgreSQL via Supabase (use Supabase client SDK)
- **Auth:** Supabase Auth (email/password + magic link)
- **Offline/PWA:** Workbox service worker + IndexedDB via Dexie.js
- **State Management:** TanStack Query (server state) + Zustand (UI state)
- **Package Manager:** npm

### CODING STANDARDS — ALWAYS FOLLOW
- TypeScript strict mode. No `any` types.
- All components are functional React with hooks. No class components.
- Use Tailwind utility classes only. No custom CSS files unless absolutely necessary.
- All database queries use parameterized statements. Never string-interpolate SQL.
- Every user-facing string uses baseball/coaching language, not clinical/academic language.
  - ✅ "mental workout" | ❌ "cognitive training session"
  - ✅ "debug your performance" | ❌ "identify psychological blockers"
  - ✅ "install your system" | ❌ "complete onboarding"
- Error states must always show a user-friendly message AND log the technical error.
