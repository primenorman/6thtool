# REPLIT IMPLEMENTATION PROMPT
## The 6th Tool — Intelligent Performance Journal System
### Framework Integration: Demartini Value Hierarchy + Axiology + Remyelination Science

---

## CONTEXT & PURPOSE

You are building an enhanced **Journal feature** for an existing web application called **"The 6th Tool"** — a mental performance training course platform for baseball players. The app is already built on Replit and contains course modules covering mental performance, bio-computer foundations, unconscious programming, and behavioral transformation.

The Journal is not a traditional diary. It is a **behavioral transformation engine** — a structured self-inquiry system rooted in three research frameworks:

1. **Dr. John Demartini's Value Hierarchy & The Demartini Method** — a system of structured questions that equilibrate distorted perception, dissolve emotional reactivity, and return the player to authentic self-governance
2. **Formal Axiology (Hartman)** — the science of value hierarchies and how they structure perception and performance
3. **Remyelination Science** — the neuroscience of how deliberate, high-quality repetition and reflection build myelin (neural insulation) that makes elite performance biologically automatic

The goal: every journal session should move the player from **amygdala-driven reactivity** toward **executive-center self-governance**, closing the gap between who they say they are and who their life demonstrates them to be.

---

## DESIGN PHILOSOPHY

**Tone**: This is not a wellness app. It is a performance laboratory. The aesthetic should feel like a high-performance cockpit — precise, focused, clean, powerful. Think: dark interface, surgical typography, intelligent use of space. The player should feel like they are stepping into a system designed to help them understand themselves at a deeper level than any coach ever has.

**UX Principle**: Every prompt the player sees should feel like it was written by a performance psychologist who has read their file. The questions are intelligent. The feedback is honest. The experience is serious — but not heavy.

**Visual Identity**: 
- Dark background (#0D0D0D or deep navy #070B14)
- Primary accent: a focused gold/amber (#D4A843) — representing excellence and signal clarity
- Secondary accent: electric blue (#3B82F6) for active states and insights
- Typography: A strong serif display font for headers (Playfair Display, Cormorant, or similar), clean mono or sans-serif for body inputs
- Subtle texture or grain overlay for depth — avoid flat corporate aesthetics
- Micro-animations on transitions (journal mode selection, section reveals, completion states)

## ARCHITECTURE OVERVIEW

The Journal system has **five distinct modes**, each targeting a different psychological and neurological function. Players select their mode at the entry point based on context.

```
JOURNAL ENTRY POINT
│
├── Mode 1: PRE-GAME PRIME         (Day-of activation & value alignment)
├── Mode 2: POST-GAME DOWNLOAD     (Performance debrief & perception equilibration)
├── Mode 3: SLUMP PROTOCOL         (Neural repair & Demartini equilibration)
├── Mode 4: VALUE AUDIT            (Weekly identity & hierarchy calibration)
└── Mode 5: NIGHTLY MYELINATION    (Sleep-prep consolidation & signal review)
```

Each mode has its own structured prompt sequence, its own data schema, and its own completion state/insight summary.

## DATABASE / DATA SCHEMA

Create the following data structure for journal entries (use your existing database — Supabase, Firebase, or local storage as appropriate for the current stack):

```javascript
JournalEntry {
  id: uuid,
  userId: string,
  createdAt: timestamp,
  mode: enum['pre_game', 'post_game', 'slump_protocol', 'value_audit', 'nightly_myelination'],
  gameContext: {
    date: date,
    opponent: string (optional),
    gameType: enum['practice', 'scrimmage', 'regular_season', 'playoff', 'showcase'],
    position: string
  },
  responses: {
    // Key-value store — each key corresponds to a prompt ID
    [promptId: string]: string | number | string[]
  },
  insights: {
    autoGenerated: string,      // System-generated synthesis of the session
    playerSummary: string,      // Player's own closing summary
    flaggedForReview: boolean,  // Player can flag an entry to revisit
    dominantEmotion: string,    // Tagged from amygdala check prompt
    valueAlignment: number,     // 1–10 scale from player self-rating
    signalQuality: number       // 1–10 neural signal quality rating (remyelination metric)
  },
  streakData: {
    consecutiveDays: number,
    totalEntries: number,
    lastEntryDate: date
  }
}
```

## MODE 1: PRE-GAME PRIME

**Purpose**: Activate the executive center before competition. Align behavior with highest values. Convert anxiety (fantasy-counterbalancing signal) into strategic objectivity. Prime the BDNF neurochemical environment for high-quality neural signal transmission.

**When used**: Morning of game day or 2–3 hours before competition.

**Estimated time**: 8–12 minutes

**UI Flow**:
1. Mode selection screen → player taps "Pre-Game Prime"
2. Brief mode description appears (1–2 sentences max, no scrolling)
3. Section-by-section prompt sequence (one section visible at a time — progressive disclosure)
4. Completion screen with auto-generated session insight

**Prompt Sequence**:

---

*Label: "Where Are You Starting From?"*

**Prompt 1.1 — Amygdala Scan**
```

[SLIDER: 1–10]
1 = "Fully amygdala — reactive, anxious, in my head"
10 = "Fully executive — clear, present, self-governed"

Don't think. First answer.
```

**Prompt 1.2 — State Identifier**
```
What's the loudest thing in your head right now?
(Check all that apply)

□ Worried about a specific outcome
□ Replaying a past performance  
□ Thinking about what others expect
□ Feeling pressure from external source
□ Comparison to someone else
□ Genuinely clear and focused
□ Something else: [text field]
```

---

### SECTION 2: VALUE ALIGNMENT ACTIVATION
*Label: "What Are You Actually Playing For?"*

**Prompt 2.1 — Highest Value Anchor**
```
Complete this sentence without overthinking it:

"At my core, the reason I play baseball is..."

[Long text input]
```

**Prompt 2.2 — Today's Specific Intention**
```

[Text input]
```

**Prompt 2.3 — Voice Sorting (Demartini: Injected vs. Authentic Values)**

## MODE 3: SLUMP PROTOCOL

**Purpose**: This is the most intensive mode. It is designed for players experiencing extended poor performance. It addresses the biological + psychological + axiological dimensions of a slump simultaneously — running cortisol reduction practices parallel to Demartini equilibration and myelination repair framing.

**When used**: After 5+ consecutive poor performances or when the player identifies they are in a slump pattern.

**Estimated time**: 20–30 minutes

**Entry Screen**: 
Display this message before the prompts begin:

> *"A slump is not a character problem. It is a signal problem — the circuitry is noisy, the perception is distorted, and the biology is running on too much cortisol. This protocol addresses all three. Take your time. There are no right answers — only honest ones."*

---

### SECTION 1: BIOLOGICAL RESET AUDIT

**Prompt 1.1 — Sleep Inventory**
```
In the past 2 weeks, rate your sleep quality:

[SLIDER: 1–10]

Average hours per night: [Number input]

Notes on sleep quality (late nights, anxiety, waking up, etc.):
[Text input]
```

**Prompt 1.2 — Cortisol Load Assessment**
```
Check every box that has been TRUE in the past 2 weeks:

□ Waking up in the middle of the night thinking about baseball
□ Replaying at-bats or pitches involuntarily
□ Feeling physically tight or contracted before games
□ Difficulty "switching off" after poor performances
□ Eating poorly or inconsistently
□ Avoiding practice or dreading it
□ Comparing your performance to teammates obsessively
□ Checking stats or social media more than usual
□ Feeling like every game is a test of who you are
```

*[System note: If player checks 5+ items, display additional message:
"Your cortisol load is high. Before the mental work can stick, the biology needs support. 
Prioritize sleep, reduce inflammatory inputs, and consider a brief aerobic session before 
your next skill work — not to train hard, but to spike BDNF and open the neural repair window."]*

Speak directly, warmly but without flattery. This player is serious about

### Streak & Engagement Mechanics

- **3-day streak**: Unlock a visual badge + brief affirmation
- **7-day streak**: System generates a "Weekly Pattern Report" — auto-summary of dominant themes across all 7 entries
- **21-day streak**: "Myelination Milestone" — system generates a "Neural Progress Report" highlighting improvement trends in signal quality and alignment scores
- **Missed day**: Gentle re-engagement prompt (NOT shame-based): *"Your circuits are waiting. 5 minutes is enough. Which mode fits tonight?"*

## TECHNICAL REQUIREMENTS

1. **Progressive Disclosure**: Show one SECTION at a time, not all prompts simultaneously. Player taps "Continue" or swipes to reveal the next section. This reduces cognitive load and increases completion rate.

2. **Auto-Save**: Save responses every 30 seconds and on every field blur. Players should never lose work.

3. **Slider Components**: All sliders should have clear endpoint labels and a visible current value. Use a smooth, weighted feel on drag.

4. **Completion Gate**: Players cannot advance to the next section with a required text field empty. Optional fields are clearly marked "(optional)."

5. **Mobile-First**: All journal modes must be fully usable on mobile — large touch targets, readable font sizes (minimum 16px body), and no horizontal scrolling.

6. **Dark Mode Only**: The journal should always render in dark theme — it is used at night (Mode 5), in pregame tunnels, and in low-light environments.

7. **Local Draft Storage**: If a player exits mid-session, their draft is saved and they are prompted to continue from where they left off when they return.

8. **Font Loading**: Load display fonts from Google Fonts (Cormorant Garamond or Playfair Display for headers, JetBrains Mono or DM Mono for input fields).

9. **Completion Animation**: Each completed section should trigger a subtle animation — not celebratory, but affirming. A soft pulse, a quiet checkmark, a clean reveal. Signal to the player that the system acknowledged their input.

10. **Entry History**: Player can access all past journal entries in a Timeline view, filterable by mode and date range.

## LANGUAGE PRINCIPLES (Apply Throughout All Prompts)

- **Never use the word "journaling"** — call it "your session," "the protocol," or "the download"
- **Never use the word "feelings"** — use "signal," "state," "read," or "data"
- **Never use "self-sabotage"** — Demartini explicitly rejects this. Use "compensation," "misalignment," or "unfulfilled value"
- **Never use empty affirmations** — no "Great job!" or "Keep it up!" Messages should be intelligent and specific
- **Use "signal quality" instead of "mental toughness"** — it's accurate, biological, and specific
- **Use "executive center" and "amygdala" as real terms** — players learn them immediately and the vocabulary becomes part of their mental model
- **Use "demonstrate" and "demonstrate your value" regularly** — this is Demartini's core language and it reinforces the framework's foundation
