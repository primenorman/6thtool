Implement analytics that track behavioral change and capability development rather than 
just engagement metrics.

SHIFT IN MEASUREMENT PHILOSOPHY:
Bad metric: "User completed 87% of videos"
Good metric: "User demonstrated IAP activation capability verified on [date]"

Bad metric: "Average time in course: 8 hours"
Good metric: "Avg practice streak: 23 days, correlation with reported performance improvement: r=0.67"

Database Schema:
```sql
CREATE TABLE transformation_metrics (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  metric_date DATE,
  
  -- Practice consistency
  current_streak_days INTEGER,
  longest_streak_days INTEGER,
  total_practice_days INTEGER,
  
  -- Capability verification
  modules_mastered INTEGER,
  capabilities_verified JSONB[], -- ['iap_activation', 'metastory_creation', 'rnbr_execution', etc.]
  
  -- Self-reported performance
  current_batting_average DECIMAL(4,3),
  performance_trend VARCHAR(20), -- 'improving', 'stable', 'declining'
  
  -- Psychological metrics
  certainty_rating_avg DECIMAL(3,1), -- Average of daily certainty ratings
  certainty_trend VARCHAR(20),
  
  -- Engagement depth
  template_submissions_count INTEGER,
  voice_memos_recorded INTEGER,
  community_contributions INTEGER
);

CREATE TABLE performance_outcomes (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  
  outcome_type VARCHAR(50), -- 'statistical', 'psychological', 'behavioral', 'competitive'
  
  metric_name VARCHAR(100), -- 'batting_average', 'strikeout_rate', 'pressure_performance', etc.
  baseline_value DECIMAL(10,2),
  current_value DECIMAL(10,2),
  improvement_percentage DECIMAL(5,2),
  
  reported_at TIMESTAMP,
  season_context VARCHAR(100) -- 'Spring 2026', 'Summer showcase season', etc.
);

CREATE TABLE user_testimonials (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  
  testimonial_text TEXT,
  specific_improvement VARCHAR(500), -- What specifically changed
  quantifiable_result VARCHAR(500), -- Numbers if available
  
  verified BOOLEAN DEFAULT FALSE,
  featured BOOLEAN DEFAULT FALSE,
  
  submitted_at TIMESTAMP,
  approved_at TIMESTAMP
);
```

ANALYTICS DASHBOARDS:

1. Individual User Progress Dashboard

Shows user their own transformation journey:
- Practice Consistency: Streak calendar, completion rate, average session time
- Capability Development: Module mastery timeline, techniques verified
- Performance Correlation: Self-reported stats before/after starting 6th Tool
- Certainty Trend: Line graph showing daily certainty ratings over time (reveals blocker patterns if certainty drops)
- Next Milestone: Clear indicator of what's needed for next achievement

2. Admin Analytics Dashboard

Aggregate insights across all users:
- Cohort Performance: Avg streak days, mastery completion rates, drop-off points
- Verification Bottlenecks: Which requirements have longest review times
- Transformation Patterns: Which modules correlate most with reported improvement
- Template Usage: Which templates most/least utilized
- Risk Indicators: Users with declining certainty, broken streaks needing intervention

Key metrics to surface:
- "83% of users who maintain 30+ day streak report measurable performance improvement"
- "Module 4 (RNBR) shows highest correlation with breakthrough experiences"
- "Users who video-record Metastory show 2.4x higher emotional authenticity scores"

3. Outcome Tracking System

Allow users to report performance outcomes:
- Statistical improvements (batting average, OBP, home runs, etc.)
- Psychological shifts ("eliminated anxiety in pressure situations")
- Behavioral changes ("now use IAP automatically between pitches")
- Competitive results ("made varsity", "earned scholarship", "drafted")

Each outcome linked to which modules/techniques user attributes improvement to.

This creates both motivational social proof and pedagogical insight into which 
components drive results.

```javascript
// Daily metrics calculation
function updateDailyMetrics(userId) {
  const today = new Date();
  const streakInfo = calculateCurrentStreak(userId);
  const certaintyRating = getTodaysCertaintyRating(userId);
  const masteryStatus = getUserMasteryStatusAllModules(userId);
  
  await db.transformationMetrics.upsert({
    where: { user_id_metric_date: { userId, metricDate: today } },
    data: {
      currentStreakDays: streakInfo.current,
      longestStreakDays: streakInfo.longest,
      totalPracticeDays: streakInfo.total,
      modulesCompleted: masteryStatus.completed,
      certaintRatingAvg: calculateRolling7DayAvg(userId, 'certainty'),
      // ... other metrics
    }
  });
}

// Transformation score calculation
function calculateTransformationScore(userId) {
  const metrics = getTransformationMetrics(userId);
  
  // Weighted composite score
  const score = (
    (metrics.currentStreakDays * 2) + // Practice consistency worth 2x
    (metrics.modulesCompleted * 10) + // Each module mastery worth 10
    (metrics.certaintRatingAvg * 5) + // High certainty worth 5x
    (metrics.templateSubmissionsCount * 1) // Engagement depth
  );
  
  return {
    rawScore: score,
    level: determineLevelFromScore(score), // 'Beginner', 'Practitioner', 'Advanced', 'Master'
    percentile: calculatePercentile(userId, score)
  };
}
```
